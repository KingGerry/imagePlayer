# 图片时间轴播放器

一个静态网页，可按日播放 `images` 目录下以 `YYYY_MM_DD.png` 命名的图片。时间轴默认展示今天，范围是从今天起往前 1 个月。

## 使用方式
1. 将图片按 `2025_12_17.png` 的格式放到 `images/` 目录下（已包含占位文件 `.gitkeep`）。
2. 在本地启动任意静态服务器（例如 Python 内置服务器）：
   ```bash
   python -m http.server 8000
   ```
3. 浏览器打开 `http://localhost:8000`，点击播放按钮或拖动滑块即可按天浏览图片。

## 功能
- 播放/暂停按天自动轮播，播放到时间轴末尾会自动停止。
- 拖动滑块立即切换到指定日期并显示对应图片。
- 时间轴范围：今天往前 1 个月到今天，默认停留在今天。
- 图片加载状态与缺失提示。
- 内置潜水蒸发量图例：垂直蓝黄橙渐变，标注 0 与 ≥1.5（mm/d）。
- 页面撑满 iframe 窗口，自适应全屏嵌入。
